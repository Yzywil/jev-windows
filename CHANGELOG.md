# Changelog

## 0.1.0a1 — 2026-09-20

Initial public alpha:

- Scoped Windows UIA backend using Windows-MCP 0.8.5's UIA module.
- One bounded Jev Choice per step over immutable compound actions.
- Preview by default, explicit UI-sharing consent, exact local grants and confirmation.
- Window/process identity binding, stale-snapshot checks and native timeout isolation.
- Exact local assertions, no replay after uncertain dispatch, redacted JSONL output.
- Offline simulator, native fixture, tests, documentation and release packaging.

This release does not claim general application compatibility or production readiness.
