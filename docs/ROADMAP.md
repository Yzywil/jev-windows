# Roadmap

No dates or compatibility guarantees are implied by this roadmap.

## 0.1 alpha — bounded foundation

One-window semantic UIA actions, exact task grants/assertions, live Jev adapter,
disposable fixture evidence, redacted logs, offline cross-platform tests and packages.

## Next: real application recipes

- Disposable Notepad/Calculator-style workflows, each with explicit UIA compatibility
  evidence and meaningful independent assertions.
- Native Toggle/SelectionItem test fixture coverage and versions/locales matrix.
- Field-value-free progress descriptions for tasks beyond form input.
- Candidate scope narrowing and actionable diagnostics for large/virtualized trees.
- More transport/worker fault injection and timing measurements, not just happy paths.

## Before any beta claim

- Repeated end-to-end evaluations on named application/version/locale combinations.
- Report failures, abstentions and human takeovers, not only successful traces.
- Publish actual request/token/latency distributions and regression thresholds.
- Dependency/API upgrade procedure proven across at least two supported resolutions.
- External review of data-sharing, task trust and action-confirmation boundaries.

No plans to add unrestricted shell execution, credential handling, automatic elevation,
silent remote access, or unattended irreversible workflows.
